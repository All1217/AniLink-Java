## 四、补充说明：为什么不用固定值？

| 方案                 | 优点         | 缺点               |
| -------------------- | ------------ | ------------------ |
| 固定值（如5条）      | 简单         | 不适应不同平台差异 |
| 固定比例（如前20%）  | 自适应       | 需实时计算         |
| **数据驱动动态阈值** | 自适应、客观 | 需定期计算         |

你的方案是**数据驱动动态阈值**，既客观又自适应，可以在论文中强调这一优势。
